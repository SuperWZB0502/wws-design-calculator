# 万唯嗣设计计算系统

面向设备选型与工程参数核算的静态网页工具。橙色区域输入参数，黄色区域自动显示结果。

支持振动筛、收尘器、皮带机、空气输送斜槽、空压机站、平底库卸空率、露天台阶爆破、铲运设备及其他补充计算，共 10 个模块、47 个计算项目。

## 使用

通过本仓库 GitHub Pages 页面访问，或下载 `index.html` 后双击离线使用。计算在浏览器内完成，无需登录。参数保存在当前浏览器，也可保存为 JSON 文件；支持载入参数、导出 CSV 和打印。

计算关系取自原始设计计算工作簿。平底库卸空率需要人工填写各层死料区面积，未填写完整时不输出相关结果。其他原始数据缺项和单位说明见页面提示与使用说明。

## 验证与发布

```sh
node tests/verify.cjs
```

自动验证嵌入网页的 785 个公式，对照 616 项有缓存的源表结果，并检查输入变化和跨表联动。

推送 `main` 分支后，GitHub Actions 自动执行验证并发布 `index.html` 到 GitHub Pages。发布目录仅包含网页和 `.nojekyll`，不包含原始 Excel、参考截图及本地维护文件。
